# UI and Accessibility Standards

The app should remain visually simple, readable, and accessible.

## Styling expectations

- Prefer Tailwind utility classes.
- Keep styles consistent and lightweight.
- Avoid custom CSS unless there is a necessary global style change.
- Do not add high-ceremony design patterns to a simple admin dashboard.

## Accessibility expectations

- Use semantic HTML.
- Use headings in a logical order.
- Ensure interactive elements are clearly labeled.
- Ensure link and button text is descriptive.
- Keep focus states and keyboard accessibility in mind when adding UI.

## Layout rules

- Keep layouts clean and easy to scan.
- Maintain spacing consistency.
- Avoid overly complex nested structures.
- Prefer straightforward page composition over decorative complexity.

## Content quality

- Keep copy direct and easy to understand.
- Use consistent terminology for product and admin features.
- Do not create placeholder-heavy UI if the task is simple.
