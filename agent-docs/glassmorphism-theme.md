# Glassmorphism Theme Guide

This project uses a purple + blue glassmorphism visual language for all UI work. Every AI-generated or human-written interface change must follow this theme unless a task explicitly requires a different design.

## Core design direction

- Use a dark layered background with soft purple and blue gradients.
- Prefer translucent glass panels with blur, subtle borders, and soft shadows.
- Keep the interface modern, airy, and premium without becoming overly decorative.
- Avoid flat white cards, harsh black surfaces, or loud neon colors that break the glass aesthetic.

## Required color palette

Use a palette close to the following values:

- Background base: #0b1020 or #0f172a
- Purple accent: #6d5efc
- Blue accent: #3b82f6
- Violet glow: #8b5cf6
- Soft white text: #eef2ff
- Frosted panel: rgba(255, 255, 255, 0.08)
- Border highlight: rgba(255, 255, 255, 0.18)
- Shadow: rgba(76, 29, 149, 0.35)

## Glass plate rules

- Panels should feel like translucent glass layers over a gradient backdrop.
- Use backdrop blur where possible, such as backdrop-blur-xl or equivalent utility classes.
- Apply soft borders with white or lavender transparency.
- Use layered shadows to create depth without making the UI heavy.
- Keep panel corners rounded and content spacing generous.

## Component styling expectations

- Buttons: purple-to-blue gradient fill, subtle glow, clear hover state.
- Inputs: translucent backgrounds with blurred white borders and stronger focus rings.
- Cards: glass surfaces with softly glowing edges and minimal content density.
- Text: high contrast but soft, with white or cool-gray tones on dark surfaces.
- Background effects: add radial or linear gradients behind content, not solid blocks.

## Layout behavior

- Keep the overall layout minimal and elegant.
- Use spacing and contrast to emphasize hierarchy instead of loud colors.
- Do not overuse decorative effects; glassmorphism should support content, not overpower it.
- Maintain readability and accessibility while preserving the premium aesthetic.

## Required instruction for AI work

When creating or editing UI in this project, AI assistants must:

1. Use the purple + blue glassmorphism design language.
2. Apply translucent panels with blurred backgrounds and subtle borders.
3. Keep the color palette consistent with the project theme.
4. Prefer soft gradients, depth, and readability over flat styling.
5. Ensure each new screen or section matches the existing minimal dashboard feel.

## Completion standard

A UI task is not complete unless the screen visually reflects the purple + blue glass plate look and remains readable, consistent, and minimal.
